DEDICATE

Digital Education Discipline & Cognitive Attention Training Environment

Home

Welcome to DEDICATE, a web-based intervention developed to help Industrial Education students reduce procrastination and improve their attention span. This platform provides tools designed to enhance focus, promote discipline, and support consistent study habits.

Task Management

A simple organizer where students can:

  • Add academic tasks
  • Set deadlines
  • Mark completed activities
  • Track pending responsibilities

Sample Draft Layout:

[ Input Task Here ] [ Select Deadline ] [ Add Task ]

• Task 1 – Due Date – [ Mark Done ]

• Task 2 – Due Date – [ Mark Done ]

This tool helps students manage their study time using time intervals.

About DEDICATE

DEDICATE is a research-based platform developed as part of the study “Development of a Web-Based Intervention to Reduce Procrastination and Improve the Attention Span of Industrial Education Students.”

The website directly supports the study’s developmental output requirement.
